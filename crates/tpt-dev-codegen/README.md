# tpt-dev-codegen

Build-time code generation with formatted output and no rustfmt dependency.

## Overview

`tpt-dev-codegen` is for `build.rs` scripts that generate Rust source. A `Writer` builds the text from the structure of its calls, so indentation and braces come out right without running rustfmt. Build helpers write a file only when its contents changed, and they print the directives that tell Cargo what to watch.

The `Writer` and the identifier and string helpers are `#![no_std]` (with `alloc`). The `build` module needs `std` and sits behind the `std` feature. Use this crate as a build dependency of the crate that needs generated code. It has no dependency on other `tpt-dev-*` crates.

## Features

- **Structured output:** `block` runs a closure one level deeper and closes the brace, so braces always balance.
- **Checked names:** constant names must be valid identifiers and not keywords. The first error is kept, and `finish` returns it.
- **Escaped strings:** `str_constant` and `string_literal` escape quotes, backslashes and control characters.
- **Change detection:** `build::write_if_changed` leaves an unchanged file alone, so dependents do not rebuild for no reason. `rerun_if_changed` and `rerun_if_env_changed` print the Cargo directives.
- **No rustfmt dependency:** output is laid out by construction, with four-space indentation.

## Installation

```sh
cargo add --build tpt-dev-codegen --features std
```

| Feature | Enables | Default |
| ------- | ------- | ------- |
| `std`   | The `build` module (`write_if_changed`, `rerun_if_changed`, `rerun_if_env_changed`). | off |

The crate is `#![no_std]` and uses `alloc`. Without `std`, only `Writer`, `Error`, `is_ident` and `string_literal` are available. A `build.rs` normally needs the `std` feature.

## Quick start

```rust
use tpt_dev_codegen::Writer;

let mut w = Writer::new();
w.line("// generated by build.rs");
w.constant("pub", "CHANNEL_COUNT", "usize", "3").unwrap();
w.block("pub fn channel_id(name: &str) -> Option<u8>", |w| {
    w.block("match name", |w| {
        w.line("\"temp\" => Some(1),");
        w.line("_ => None,");
    });
});
let source = w.finish().unwrap();
assert!(source.starts_with("// generated by build.rs\npub const CHANNEL_COUNT: usize = 3;\n"));
assert!(source.contains("        \"temp\" => Some(1),\n"));
```

### Checked names and escaped strings

```rust
use tpt_dev_codegen::{Writer, is_ident, string_literal};

assert!(is_ident("sensor_count"));
assert!(!is_ident("fn"));

let mut w = Writer::new();
w.str_constant("pub", "GREETING", "say \"hi\"").unwrap();
assert!(w.constant("", "not valid", "u8", "1").is_err());
// The first error is kept, and `finish` returns it.
assert!(w.finish().is_err());

assert_eq!(string_literal("a\nb"), "\"a\\nb\"");
```

### In a build script

In a real `build.rs`, write the generated source into `OUT_DIR` and watch the inputs. The snippet below uses a temporary directory so that it can run as a doctest, and it only compiles with the `std` feature.

```rust
# #[cfg(feature = "std")]
# {
use std::path::Path;
use tpt_dev_codegen::build::{rerun_if_changed, write_if_changed};

let input = Path::new("channels.txt");
rerun_if_changed(input); // prints a `cargo:rerun-if-changed=` line
let source = "pub const CHANNEL_COUNT: usize = 3;\n"; // built with Writer
let out_dir = std::env::temp_dir().join("tpt-dev-codegen-readme");
std::fs::create_dir_all(&out_dir).unwrap();
let out = out_dir.join("gen.rs");
write_if_changed(&out, source).unwrap();
// A second call with the same contents leaves the file alone and returns false.
assert!(!write_if_changed(&out, source).unwrap());
# }
```

In `build.rs` itself, the output path is `Path::new(&std::env::var("OUT_DIR").unwrap()).join("gen.rs")`.

## Design notes and guarantees

- **Balanced braces:** `block` writes the closing brace after the closure returns, so a block cannot be left open.
- **First error wins:** a bad constant name is recorded on the writer, and `finish` returns that first error. `constant` also returns the error at the call.
- **Keyword list:** `is_ident` accepts ASCII letters, digits and `_` (not starting with a digit) and rejects a fixed list of Rust keywords, including reserved ones such as `async`, `try` and `gen`.
- **Idempotent writes:** `write_if_changed` reads the existing file and writes only if the contents differ. It returns `true` if it wrote.
- **No `unsafe` code.**

## Limitations and scope

- **Expressions are not parsed.** `constant` writes its value as given, so an invalid expression is only caught when the generated code is compiled. Only names and string literals are checked.
- **Layout is structural, not formatted.** Long lines are not wrapped, and the writer does not reformat code it did not generate.
- **ASCII identifiers only.** `is_ident` rejects non-ASCII names, which Rust itself allows.
- **The build helpers need `std`.** They are behind the `std` feature.
